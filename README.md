Inkbloom
A cozy, warm-toned personal blogging platform — thoughts, notes & things that matter.
Built with PHP + MySQL. See `SETUP.md` for local setup instructions.
Highlights
Write & publish posts with a Markdown editor, cover images, and inline image uploads
Browse by topic, search, like, and bookmark posts
Light/dark mode with a smooth animated toggle (remembers your preference)
"Continue with Google" / "Continue with GitHub" social sign-in (optional — add your own OAuth credentials in `config.php` to turn it on)
Newsletter sign-up, reading progress bar, image lightbox, and tasteful micro-animations throughout
